## Ecosistema UMA OS v1 — Demo Conceptual
*Sede Proyectada: Asturias, España*

---

### 🚀 ¿Qué es UMA OS?
UMA OS es un proyecto de sistema operativo móvil diseñado para romper con la arquitectura tradicional de cuadrículas de aplicaciones. Este repositorio contiene el núcleo lógico base escrito en Python para validar los sistemas de respuesta y seguridad simbiótica de la interfaz.

### 🛡️ Características Implementadas en la Demo (`uma_core.py`):
* **Arranque del Sistema Operativo:** Inicialización del núcleo lógico optimizado.
* **Protocolo de Seguridad Simbiótica:** Validación dual que detecta la presencia de hardware dedicado externo.
* **Módulo de Contingencia Bajo Presión:** Si el sistema detecta un estado de estrés simulado mediante métricas elevadas en el momento del desbloqueo, el sistema desvía automáticamente el entorno hacia una **Interfaz Espejo Falsa**, protegiendo los datos confidenciales del usuario real.

---

### 💻 Cómo probar la demo de forma local:
Si tienes un entorno con Python 3 instalado, puedes ejecutar el núcleo con el siguiente comando en la terminal:
\`\`\`bash
python3 uma_core.py
